# AI 포니봇 반려로봇 — 수신 코드 설치

1. https://makecode.microbit.org 에서 새 프로젝트를 만듭니다.
2. 확장 메뉴에서 `bluetooth`를 추가합니다. 안내가 나타나면 radio를 제거합니다.
3. 확장 메뉴에 `https://github.com/boundary-x/ai_ponybot_basic`을 입력해 추가합니다.
4. JavaScript 탭에서 기본 코드를 지우고, 이 폴더의 `main.ts` 내용을 붙여 넣습니다.
5. 프로젝트 설정에서 블루투스 페어링을 **필요하지 않음**으로 선택합니다.
6. 마이크로비트에 다운로드하고, 포니봇 모터 전원을 켭니다.
7. 웹앱에서 **포니봇 연결하기**를 누릅니다. 연결 후 **몸짓 함께하기**를 켭니다.

모터 위치는 위에서 보았을 때 오른쪽 앞 1, 오른쪽 뒤 2, 왼쪽 뒤 3, 왼쪽 앞 4입니다.
양수는 확장 블록의 Clockwise, 음수는 CounterClockwise로 전달합니다. 확장 내부의 모터 3·4 방향 보정을 그대로 사용합니다. 실제 배선에 따른 진행 방향은 먼저 바퀴를 지면에서 띄워 확인하세요.

이 수신 코드는 신규 프로토콜 전용입니다. 블루투스 이름 확인 코드만 설치한 상태에서는 구동되지 않습니다.

## 작동 원리

`M+40+40-40-40T300` 뒤의 줄바꿈을 받을 때까지 기다립니다.

- `+40 +40 -40 -40`: 모터 1, 2, 3, 4의 속도와 방향
- `T300`: 300ms 동안 실행
- `S`: 바로 정지

명령이 잘못되거나, 동작 시간이 끝나거나, 블루투스가 끊기면 정지합니다. 다음 명령이 오지 않아도 마지막 동작은 최대 600ms 뒤에 끝납니다. 전진 속도는 80 이하로 제한합니다.

웹앱의 ‘전송’은 브라우저의 블루투스 쓰기 완료를 뜻합니다. 실제 구동 확인 응답은 포함하지 않습니다.

현재 코드의 파싱과 시간 만료 동작은 시뮬레이션으로 검증합니다. 실제 MakeCode 컴파일·블록 변환 및 포니봇 하드웨어 테스트는 별도 확인이 필요합니다. 장애물·낙하 회피 기능은 포함되지 않습니다.
