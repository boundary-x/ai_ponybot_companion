모터 위치: 오른쪽 앞 1 · 오른쪽 뒤 2 · 왼쪽 뒤 3 · 왼쪽 앞 4. 이 버전에는 장애물·낙하 회피 기능이 없으므로 바닥의 빈 공간에서 테스트하세요.

문제 해결 증상별 안내
포니봇 연결이 안 돼요

수신 코드를 설치하고 다른 앱의 블루투스 연결을 해제하세요. PC·안드로이드는 Chrome 또는 Edge, iPhone은 Bluefy에서 테스트하세요. 실제 연결 가능 여부는 브라우저와 기기에 따라 달라집니다.

말하거나 효과음을 들을 수 없어요

화면을 한 번 터치해 소리를 활성화하세요. 음성 입력은 AI 연결과 마이크 권한이 필요합니다. 마이크 버튼을 누른 채 말하고 떼면 전송됩니다. 최대 8초까지 녹음하며, 준비 중에 버튼을 떼면 취소됩니다.

카메라나 AI가 연결되지 않아요

카메라 권한과 인터넷 연결을 확인하세요. AI 오류는 설정 창과 화면 안내에 표시됩니다. API 키 권한, 사용량, 선택한 모델 이름을 확인하세요.

연결했는데 움직이지 않아요

‘몸짓 함께하기’를 켜세요. 연결 직후, 전체 정지, 탭 이동 후에는 움직임이 꺼집니다. 모터 수치는 전송 명령이며 실제 바퀴 속도를 측정한 값은 아닙니다.

동작 원리와 전송 데이터

입력 → 반응 생성 → 값 검사 → 표정·소리·모터 실행 순서입니다. AI는 최대 6개의 짧은 동작을 생성합니다. 모터 값은 -80~80, 한 동작은 50~600ms로 제한합니다.

M+40+40-40-40T300\n — 모터 1·2·3·4의 부호와 두 자리 속도, 세 자리 지속 시간(ms), 줄바꿈입니다. 총 18바이트입니다. S\n은 정지입니다.

수신 코드는 동작 시간 만료 또는 연결 해제 시 정지합니다. 화면의 ‘전송’은 블루투스 쓰기 완료이며, 실제 모터 구동 확인 응답은 아닙니다.
